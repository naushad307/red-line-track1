Kisi mast, station, ya track ke kisi bhi point par click/tap karein — chainage, line, rail (L/R) aur span ki poori detail yahan aur ek floating tooltip me (10 second ke liye) dikhegi.

🩵 Curve zones: Curve register (ULC/DLC, Curve-2026_New-1.xlsx) se UP line par ULC ke 79 aur DOWN line par DLC ke 76 curve embed kiye gaye hain. Halke blue band = curve ka poora extent (ST se TS tak, transition + circular). Us band par click/tap karke curve no., section, radius, transition length, OHE mast between, between chainage, cant, degree, LH/RH type, max speed etc. dekh sakte hain.
🩷 Points: Point register (point_detail_line-01_2026.xlsx) se 59 points embed kiye gaye hain — DOWN line ke points DOWN track par, UP line ke UP track par, halke pink diamond marker se. Click/tap karke point no., station, OHE mast between, angle of crossing, LH/RH, date of laying dikhega.
📝 Manage Data: Header ke "Manage Data" button se Points, Curves, Stations/Sections (Opening Date + Platform Length) — sabhi add/edit/delete kar sakte ho. Opening Date source Excel me nahi thi, isliye khali hai — yahi form se bhar sakte ho. Sab changes turant map par reflect hote hain.
💾 Save / Load: Header me "💾 Save" button Admin ke liye MongoDB me current data save karta hai. Kisi bhi tab (Points, Curves, Replacement, Reversal, GMT, Stations) me change karo, "● Unsaved changes" dikhega; Save dabane par MongoDB update ho jayega. "Export All" se local JSON backup alag se download kar sakte ho.
🟤 Rail Replacement: Manage Data → "Rail Replacement" tab se naya replacement record add karo (Date, Section, UP/DOWN, LH/RH rail, Chainage From-To, OHE From-To, Length, Reason, Rolling Marks). Ye us exact chainage par, us line ke sahi rail (Left/Right) par brown color me dikhega — aur hamesha baaki sabhi layers (curve, reversal, point) ke upar show hoga.
🟥 Curve Reversal: "Curve Reversal" tab se add karo (Date, Section, Curve No., UP/DOWN, Chainage From-To, OHE From-To, Length, Reason). Ye light-red band ki tarah dikhega jo us line ke dono rail (Left+Right) ko cover karta hai. Sabhi (Points, Curves, Replacement, Reversal) par click/tap se 10-second tooltip me poori detail milegi.

Structure (aapke sheet jaisi): har Main Section (jaise "Main section 1") ke andar Sub-section naamo ki ek list hoti hai (Sub section 1, 2, 3...) — ye kisi bhi order me ho, phir bhi us Main Section ka hi mana jaata hai. Uske niche ek FY-wise table hai: FY Year | GMT (us saal ka) | Starting Date | Close FY Date — ye poore Main Section ka common data hai (section jab se khula hai, tab se). Point ki "Station", Rail Replacement ki "Between Section", ya Curve ki "Section" — in teeno me se jo bhi text kisi Sub-section ke naam se match karega, uska GMT usi Main Section ki FY-table se calculate hoga: agar wo replacement hai, to uski GMT uske apne replacement date se count hogi (section-opening date se nahi) — per-day rate nikalkar aage ki FY-years jodte hue. "+ Add Main Section" se naya Main Section (apni 3 columns — GMT, Starting Date, Close FY Date — ke saath) jud jaata hai.

🔗 Section Commission link: Agar "Section Commission" tab me kisi record ka Section From/To is Main Section ke kisi Sub-section naam se match karta hai, to yahan har Main Section ke upar wo Commission Date dikhegi, aur "⬇" button se ek click me pehli FY row ki Starting Date usi Commission Date se bhar sakte ho.
Har row ek section-segment ka Opening/Commission Date record karta hai: Section From, Section To, aur uski Opening/Commission Date. Add karke Save/Delete kar sakte ho. 🔗 Ye records GMT Data tab se automatically link ho jaate hain — jis Main Section ke Sub-section naam se yahan ki "Section From/To" match kare, wahan is Commission Date ko dikhaya jaayega (aur FY table ki pehli Starting Date yahi se ek-click me bhari ja sakti hai).

Setup — sirf ek baar karna hai:

🗄️ MongoDB Database: Ye application direct MongoDB backend se connected hai. Google Sheet ya Apps Script ki koi zaroorat nahi hai.

Database modules: Points, OHE Mast (UP/DOWN), Stations, Curves ULC/DLC, Rail Replacements, Curve Reversals, GMT, Section Commission, Crossing Replacements, Switch Replacements, AT Welds, Station Platforms aur Sections Master.

🔒 Security: Normal User ko sirf View permission milegi. Admin ko Manage/Edit/Save permission milegi. Kisi user ko API token enter karne ki zaroorat nahi hai. Admin creation aur Admin password reset ke liye server-side Admin Verification Code required hai.

🔄 Auto-Sync: Login ke baad app MongoDB ka latest version check karta hai. Admin ke Save ke baad doosre users latest data fetch kar sakte hain.
🔍 Test Connection — MongoDB backend connection check karega; kisi token ki zaroorat nahi.
⬇ Fetch — MongoDB ka pura data laakar is app ke andar (Points, Curves, Replacements, Reversals, GMT, Stations, sab kuch) replace kar deta hai — jo abhi app me hai wo overwrite ho jaayega.
⬆ Push — is app me jo bhi data/edits hain, wo saare MongoDB me save kar deta hai (existing records ko replace karke fresh data save karta hai) — Sheet me jo tha wo overwrite ho jaayega.
🔄 Auto-Sync — on karne par app har 10 second me MongoDB version check karta rahega — MongoDB me kuch bhi update karo, thodi der me (max 10 sec) yahan bhi dikh jayega, bina button dabaye. (Ye "polling" hai, real-time push nahi — server-side MongoDB polling ke through latest version detect hota hai.)
User केवल View कर सकता है। Admin ही Manage Data और MongoDB में Save/Push कर सकता है। Login accounts server-side MongoDB में सुरक्षित रहते हैं।
⬇ CSV aur 🖨️ PDF download ab har Manage Data tab ke andar, uske apne toolbar me milega — sirf usi tab ka data download hota hai (jaise Points tab me sirf Points, AT Weld tab me sirf AT Weld). OHE Mast Chainage tab me sirf CSV hai (PDF nahi, kyunki 2000+ rows PDF ke liye bahut zyada hai).
